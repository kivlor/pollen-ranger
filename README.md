# 🌱 Pollen Ranger

> A first-person greenhouse reclamation game — MDK meets Metroid Prime in a tiny, tangled world.

![Godot Engine](https://img.shields.io/badge/Godot-4.7-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## The Pitch

You are a **thumb-sized woodland scout** — a seed-pod golem with acorn armor — dropped into an enormous, overgrown greenhouse consumed by a creeping gray rot known as **The Blight**.

Armed with a dandelion-seed sniper rifle and a fluff-parachute glider, you must purge the corruption, restore the blooms, and reclaim the greenhouse biome by biome.

## Features

- 🎯 **Dandelion Sniper** — Tag blighted fruit from 200 feet away through your bamboo scope. Shoot water droplets onto dry soil to spawn sunflower trampolines.
- 🪂 **Aero-Gliding** — Deploy your dandelion-fluff parachute to float between hanging baskets and rafters.
- 🌿 **Biome Reclamation** — Defeat Queen Weevils to cleanse sectors. Sunlight breaks through, vines grow, new paths open.
- 🐛 **Boss Battles** — Face off against corrupted garden denizens in each biome.

## Biomes

| Biome | Theme | Unlock |
|-------|-------|--------|
| Entrance Conservatory | Tutorial | Starting area |
| Orchid Tropics | Humid, vertical | Defeat Queen Weevil I |
| Cactus Desert | Dry, hazardous | Clear 50% Blight |
| Compost Catacombs | Dark, fungal | Full game access |

## Development

Built in **Godot 4.7**. Currently in early development.

### Running

```bash
# Clone the repo
git clone git@github.com:kivlor/pollen-ranger.git
cd pollen-ranger

# Open in Godot Editor
godot --path .
```

### Requirements

- Godot 4.7+
- OpenGL 3.3+ compatible GPU

## Inspiration

- **MDK (1997)** — The ribbon-chute glider and long-range sniping
- **Metroid Prime** — First-person platforming and scan visor
- **Kena: Bridge of Spirits** — Cleansing corruption with satisfying particle effects
